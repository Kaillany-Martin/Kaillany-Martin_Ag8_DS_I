# Pesquisa de Satisfação atividade ADS

### Objetivo do projeto
O projeto introduz os contadores e a estrutura de repetição, como pedido na tarefa do fichário. Tem como objetivo exibir uma primeira mensagem com um titulo autoexplicativo sobre o uso do programa e inicia uma contagem de avaliações de atendimento ao cliente, repetidas 50 vezes (apenas 10 na imagem em anexo dos teste). No fim é exibida a contagem para as respostas "Excelente" e "Ruim", excluindo a contagem de "Bom".

### O que foi praticado

  - input
  - int
  - \n
  - if/elif
  - repetiçaõ for
